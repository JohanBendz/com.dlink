# Security and privacy reports

Please **do not post secrets or unredacted diagnostic data in public Issues or Pull Requests**.

If you discover a security vulnerability or accidental exposure, contact the maintainer privately at **homey@bortbytt.se**. Include the affected component, a short reproduction and the likely impact. Do not include any real device PIN or password unless a secure exchange has been agreed.

For regular Wi-Fi/HNAP debugging, please redact PINs, passwords, cookies, authorization headers, real public IP addresses, and device identifiers before sharing logs.

This project is maintained on a best-effort community basis.
