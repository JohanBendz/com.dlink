Control compatible D-Link smart-home devices on Homey over Z-Wave and local Wi-Fi/LAN.

Supported Z-Wave devices:
- DCH-Z110 door/window sensor
- DCH-Z120 motion sensor
- DCH-Z122 motion sensor
- DCH-Z310 smoke detector
- DCH-Z510 multisound siren

Supported local Wi-Fi device:
- DSP-W215 smart plug (on/off, power measurement and internal plug temperature)

The DCH-Z510 includes Flow actions for siren control, sound selection and enabling or disabling the alarm.

For support, feedback and device requests visit https://github.com/JohanBendz/com.dlink/issues
