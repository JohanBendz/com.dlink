Control compatible D-Link Z-Wave and Wi-Fi devices locally with Homey.

Supported Z-Wave devices:
- DCH-Z110 door/window sensor
- DCH-Z120 motion sensor
- DCH-Z122 motion sensor
- DCH-Z310 smoke detector
- DCH-Z510 multisound siren with Flow actions

Supported local Wi-Fi/LAN devices:
- DSP-W215 smart plug: on/off, power usage and internal temperature
- DCH-S220 siren: on/off, selectable sounds, volume and duration, and Flow actions

Wi-Fi devices use local network communication and their own six-digit device PIN. Compatibility can vary between hardware and firmware revisions. Please report your experiences to help us improve device support.

The siren integration is intended for home automation. Do not use it as the sole means of warning for safety-critical events.

Support and device requests: https://github.com/JohanBendz/com.dlink/issues
