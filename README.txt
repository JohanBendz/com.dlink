Control compatible D-Link smart home devices using Z-Wave on Homey.

Supported devices:
- DCH-Z110 door/window sensor
- DCH-Z120 motion sensor
- DCH-Z122 motion sensor
- DCH-Z310 smoke detector
- DCH-Z510 siren

The DCH-Z510 siren also supports Flow actions for on/off, sound selection and enabling or disabling its alarm.

For help, feedback and device requests, visit the project's GitHub issue tracker: https://github.com/JohanBendz/com.dlink/issues
